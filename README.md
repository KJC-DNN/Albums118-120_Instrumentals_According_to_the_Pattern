# Instrumentals — According to the Pattern
(Consolidated set covering Albums 118–120)

According to the Pattern — Instrumentals for Albums 118–120

Fourteen instrumental tracks for Albums 118–120. No vocals. The pattern shown. The veil torn. Evening and morning. Quiet worship. Open sky, empty wooden cross, open Book. Not a replacement for the vocal albums.
